# A & A Wedding Invitation — Vercel Ready

This is a static wedding invitation website. It can be deployed directly to Vercel.

## Quick start

1. Unzip this folder.
2. Open `index.html` locally to preview it.
3. Replace the dummy names, dates, venue and WhatsApp number in `index.html`.
4. Replace image URLs with your own photos if desired.
5. Put your music file in this folder as `music.mp3`.
6. Upload the folder to a GitHub repository.
7. In Vercel, import that GitHub repository and deploy.

No build command is required for this static version.

## Main files

- `index.html` — all wedding content
- `styles.css` — design and responsive layout
- `script.js` — countdown and music button
- `music.mp3` — optional; add your own audio file
